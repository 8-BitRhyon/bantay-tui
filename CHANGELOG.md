# Changelog

All notable changes to this project are documented in this file. The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- **Notification Dismiss Mute** (`NotchStatusView.swift`, `IslandMetrics.swift`): X on a done card now clears the completed stack and mutes done notices for five minutes. X on a failed card keeps that agent's failure down for ten minutes. Approvals and questions are never muted, and a done X no longer acknowledges an approval. Pending settle tasks re-check the mute after the settle window, so a dismissed card cannot pop back.
- **Exact-Agent Focus** (`FocusTelemetry.swift`, `NotchStatusView.swift`, `AgentRowView.swift`, `NotchCommonViews.swift`, `AgentPresentation.swift`, `NotchRosterView.swift`): Clicking an Antigravity conversation now opens that exact chat through the IDE URI handler, while multiplexer rows keep exact pane routing. Focus attempts are logged locally for the 7-day success metric. Rows gain an Amicro-style slide-arrow Focus pill and a read-only quota headroom badge; quota headroom is a group sort tiebreaker only. `scripts/focus-report.py` reports the metric without storing titles or prompt text.
- **Antigravity Per-Agent Rows** (`AntigravitySummaryStore.swift`, `AgentDetector.swift`, `AgentEventManager.swift`): Reads the CLI hub's `conversation_summaries` registry, the same active list the Antigravity webview builds from `notFullyIdle`, `parentConversationId`, and `subagentSpec`. Each active conversation becomes its own row with its run status, subagent role, parent depth, and workspace. Root chats and subagents no longer collapse into one idle Antigravity source row.
- **Antigravity CLI Root Detection** (`AntigravityStore.swift`): Reads both the IDE and CLI/hub conversation stores, dedupes by conversation ID, and uses the WAL mtime as the working heartbeat. Agents launched through the IDE hub now show working instead of idle.
- **Spend Clarity** (`SpendHistoryStore.swift`, `SpendHistoryView.swift`): The daily card now distinguishes metered dollars from subscription usage. When a provider records tokens but no cost, Today shows the token count and says no metered spend was recorded, with subscription usage in Quotas. Today by Agent lists per-agent tokens beside cost. Existing records decode unchanged.
- **Notification Dismiss Split** (`NotchStatusView.swift`): Completion and failure cards now show an explicit Open button beside X. X dismisses the notice and keeps the notch visible for a short beat, so the last card no longer takes the plane down with it.
- **Antigravity Provider Quota** (`AntigravityQuota.swift`, `QuotaAxiTracker.swift`, `ProviderQuotaView.swift`): The Quotas view decodes the IDE's cached `userStatus` protobuf into a provider-reported remaining percentage and reset time, using the lowest per-model fraction across the models. The reported row and the measured session row now share one Antigravity group with distinct ids and labels. A cached window whose reset already passed renders as STALE and never drives quota rerouting. Credit counts stay undecoded until their field mapping is proven.
- **Media Shelf Drag-In and Drag-Out** (`ShelfPasteboardReader.swift`, `ShelfDrop.swift`, `ShelfDragProvider.swift`, `ShelfModel.swift`, `ShelfStore.swift`, `NotchShelfView.swift`, `NotchStatusView.swift`, `FileDropContentView.swift`): Browser images, files, links, and dragged text now land on the shelf. Dropped bytes become real files in Bantay storage. Drag a card back into Finder, an upload field, or an editor. Images offer a file URL, PNG, and TIFF. Links offer a URL and text. Text offers plain text. The island stays open until the drag ends.
- **Media Shelf Hardening** (`ShelfStorage.swift`, `ShelfDrop.swift`, `ShelfStore.swift`, `NotchShelfView.swift`, `NotchTabBarView.swift`, `IslandMetrics.swift`, `NotchHUDConfig.swift`, `SettingsView.swift`): The shelf now enforces a 1 GB storage budget, configurable from 64 MB to 10 GB. Oldest items are evicted first. Drop writes are serialized so rapid batches cannot race. Folders, symbolic links, and missing sources are rejected with a specific reason, and an oversized item never clears the shelf. A startup, periodic, and on-open sweep removes expired items, orphaned files, empty directories, and symlinks without following them. The shelf footer shows usage, loading, and per-drop failures. Clipboard rows scroll within the panel cap. A drop that forces the hidden shelf open also renders the tab bar so the panel keeps an escape route.
- **Closed Strip Choice** (`IslandMetrics.swift`, `NotchIdleStripView.swift`, `NotchHUDConfig.swift`, `SettingsView.swift`): The strip beside the notch now offers four modes: lead project plus working count, working count alone, agent name chips, and status dots. Project mode groups agents by folder, folds other projects into `+N`, and is the default for new installs. The choice persists and applies to centered and docked placements. A quiet notch no longer renders an `Idle` capsule.
- **Desktop Strip HUD** (`DesktopHUDController.swift`, `DesktopHUDView.swift`): Bottom-center window-only surface with column cards, Chain, Overview, navigation, and a Layout menu. Opens with `⌃⌥Space`, the menu bar, or `bantay strip hud`. Auto-hides unless pinned. Never appears in full screen. The notch no longer renders window controls.
- **Unified Approval Cards** (`ApprovalCardView.swift`): Blocked agents render as cards. Each card shows the exact request, risk badge, and queue position. Actions are Allow Once, Review, and Deny. Supports yes-no, numbered choices, and multi-select prompts.
- **Humanized Agent Rows** (`AgentPresentation.swift`, `AgentRowView.swift`): Raw tool text maps to plain status lines. Risk tiers flag destructive commands. Subagents fold under their project. Clicking a row focuses its window. Reply uses `R` or the row menu.

- **Approval Safety and Desktop HUD Sections** (`SettingsView.swift`): New Agents policy section and Desktop HUD behavior section. Categories renamed to Notch and Desktop. All preference keys stay unchanged.

Questions show their options with an Answer action and never Approve or Deny. The closed card, the compact pill, and Notification Center copy all follow the same rule.
- **Notification Queue** (`IslandMetrics.swift`, `NotchStatusView.swift`, `DynamicIslandApp.swift`): Closed cards stack up to five deep with a stepper. New arrivals never replace the card being read. The menu bar offers Answer or Review for questions and waiting states, never Approve or Deny.
- **Multi-Select Everywhere** (`IslandMetrics.swift`, `NotchStatusView.swift`, `DynamicIslandApp.swift`, `ApprovalNotificationController.swift`, `AgentAlertNotifier.swift`): Pick-several prompts work in the closed popup. It shows up to six options with a count. Submit stays disabled until something is picked. The menu bar gets checkmarked toggles plus Submit. Banners and phone push offer Answer and Review only. One-tap buttons would partial-answer, so they are gone. Question push drops Deny.
- **Popup Card Fixes** (`IslandMetrics.swift`, `NotchStatusView.swift`): Multi-select options render as a labeled two-column toggle grid. Each chip shows its number and label with a checkmark. The card grows to fit the grid. The bare-number row and its duplicate text line are gone. Live pane excerpts show only text with a prompt signal. Random transcript text falls back to Review.
- **Sessions Rebuild** (`UsageTracker.swift`, `AgentEventManager.swift`, `NotchHistoryView.swift`, `IslandMetrics.swift`): Finished sessions record their own token and cost delta, never the lifetime total. One row per working burst: repeat completion heartbeats no longer multiply rows. Rows without an observed start show a lifetime label and stay out of the sums. Rows carry project, branch, and transcript path. The tab groups by day with search and agent filter. Each row expands to Transcript, Reveal, and Copy actions. Lifetime counters accrue from appended bytes only. Change detection is per file, never root mtime. opencode meters from its monotonic ledger sums. Session deltas use lifetime counters with a labeled window fallback. Spend leads with ledger Lifetime, 7-day, and 24-hour scopes. Streak, active days, and session count come from day buckets. Every scope states its window.

Own EventKit writes suppress their echo for three seconds. A denied grant deep-links to System Settings instead of re-prompting. The Reminders section names its list. Stale placeholder rows are gone.

### Fixed

- **Smooth Permissions** (`Permissions.swift`, `SettingsView.swift`, `DynamicIslandApp.swift`): Grants were scattered (a strip grant button here, a log line there) and named by mechanism, not by what they unlock. Settings > General now has a Permissions section: Accessibility (answer agents, focus inputs, tile windows), Input Monitoring (global hotkeys), and Notifications (banners while hidden), each with live status, a Grant button, and a System Settings shortcut. Status polls while the window is open, so a grant lands in place; an Input Monitoring grant re-arms the hotkey monitors without relaunching. Notification checks are bundle-guarded, since `UNUserNotificationCenter` crashes outside an app bundle. The hotkey log line names the exact missing grant.
- **Tasks Stop Duplicating** (`TaskStore.swift`, `RemindersProvider.swift`, `TaskWidgetView.swift`): A 19k-row pileup traced to missing guards, not a sync loop. `addTask` now returns the open identical task instead of inserting a duplicate, and it only clears the deleted-item guard after the reminder write succeeds and links the created reminder back, so completion, reopen, and remove hit the exact reminder via a two-pass match (externalID first, title only among unlinked tasks) instead of the first same-title row. Tombstones persist to a sidecar file so deleted tasks stay deleted across relaunch, a generation-gated flush makes relaunch reads deterministic, and an in-flight guard plus a delayed re-sync replace the old drop-suppressed-echo behavior. Tag-stripped titles no longer collapse distinct reminders ("Buy milk @work" vs "@home"), and delete offers 5s Undo that restores the exact task.
- **Tasks Tab UX Pass** (`TaskWidgetView.swift`): One entry point (the top field creates the task and its reminder; the duplicate quick-add is gone), the Reminders box only shows items not already in the task list with a REMINDERS badge on synced tasks, empty states distinguish no-tasks from no-match (with Clear search) and offer Connect Reminders, pending work shows a Queued badge with Retry on blocked or failed, the Completed header drops the emoji for a count, the sound honors the alerts switch, and row buttons meet the 28pt target.
- **X and Focus, Made Consistent** (`AgentEventManager.swift`, `NotchStatusView.swift`, `NotchCommonViews.swift`, `AgentRowView.swift`, `DynamicIslandApp.swift`): The dismiss X and focus buttons felt random. Three causes: icon buttons had sub-20pt hit targets (now a 28 by 26 minimum everywhere), invisible hover controls on roster rows were still swallowing clicks meant for the row (they now take hits only while visible), and focusing a Herdr pane switched the pane inside the multiplexer without ever raising the terminal window, so from another app the click appeared to do nothing (the terminal now comes forward too). A dismissed prompt could also resurrect when a bare status heartbeat re-emitted it: dismissal is now recorded per pane, bare heartbeats stay down, and a genuinely new question on the same pane still surfaces. The hotkey monitor's permission log now names the actual missing grant (Input Monitoring for hearing keys, Accessibility for sending them), following the per-capability split Hex uses.
- **Ghost Agents and IDE Focus** (`AgentDetector.swift`, `NotchStatusView.swift`, `KeyboardSynthesizer.swift`): Codex and Claude rows appeared for tools nobody was running. The standalone scan now classifies only the command part of each `ps` line: the appended environment is stripped first, after a tmux attach (codex in its PATH) and a Dia agent-server were both promoted to agents by environment text. Herdr-managed filtering, fixed earlier, now gets real environment data to work with. Focusing a chat-first IDE (Antigravity, Cursor, Windsurf) no longer stops at raising the window: after activation it focuses the composer input with Cmd+L, so Focus ends where the user types.
- **Every Panel Button Earns Its Place** (`NotchHeaderBarView.swift`, `NotchTabBarView.swift`, `NotchStatusView.swift`, `NotchRosterView.swift`, `AgentRowView.swift`, `ApprovalCardView.swift`, `PeekPanel.swift`, `AgentPresentation.swift`): A full audit of the expanded panel found traps and silent failures. Hiding the Shelf tab removed the entire tab bar and stranded the selected view; the tab bar now renders while any tab is reachable, and a hidden selected tab reconciles to the first visible one on expand. The bell, working-count, spend, and token-rate badges are real buttons now (Inbox, Spend), and the quota badge already was. Clicking a roster row now focuses the exact pane through the adapter instead of raising a terminal by app-name guess, and a router with no opinion falls back to direct pane focus. Keyboard Enter can no longer blind-approve a review-only row, and roster Enter opens the peek panel instead of fetching text nobody rendered. Approval cards surface decision failures in the card and disable choices when the transport cannot carry them. The peek panel keys its toggle by agent identity, so two standalone agents of one source no longer collide. Row clicks use one exclusive gesture, so double-click compose cannot also fire focus. "Open Workspace" opens the agent's real cwd or nothing, never a guessed directory. Working headlines drop the "OC |" terminal prefix, the Working section counts only agents actually working (it could disagree with the header badge), same-project truncation now sacrifices the branch before the project name, the collapsed subagent row names its first subagent, and the gear opens General settings instead of Agents.
- **Phantom Roster Agents** (`AgentDetector.swift`, `AgentPresentation.swift`, `AgentRowView.swift`): The standalone process scan never captured process environment, so its herdr-managed filter always passed: every OpenCode client inside a Herdr pane also appeared as a standalone agent, the herdr daemon listed itself as a working agent, and an "OpenCode update available" transcript tail promoted a phantom row to Working. A new read-only store decodes the IDE conversation database: each step's protobuf metadata carries the tool action and a human summary, which is now the headline the roster shows ("Listing apps in /Applications", not raw text). Working state comes from the store heartbeat. Finished conversations are recorded as sessions once, with honest zero tokens (no usage fields exist in the store, and none are invented). The Quotas view gains a measured Antigravity row (steps and conversations, home-scoped). The tool vocabulary covers find, code search, URL reading, image generation, browser, and planning steps. Checkbox pickers without number hotkeys get an arrow-and-Space plan that only toggles rows whose state must change. Waiting and question events enrich from the live pane even when the event title is only the terminal title.
