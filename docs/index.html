What it offers

One sentinel for every agent you run

Run as many agents as you like, in as many panes as you like. Bantay watches all of them from one place and only calls you when a decision is actually yours.

APPROVALS

Decide without switching panes

Every permission request arrives with the exact command, path, or question and a risk badge. Allow once, deny, or pick from numbered choices. The card only leaves after the answer is confirmed delivered, and every decision leaves a receipt.

QUESTIONS

Answer questions where you sit

When an agent asks, the notch copies its form faithfully: one tappable row per option, each option's consequences underneath, checkboxes for multi-select, and a field for your own answer when none of the options fit.

QUIET BY DEFAULT

Interrupted only when it matters

Agents cry "done" at every turn. Bantay waits for a finish to settle, holds completions silently while you work in another pane, and never pops a finish you watched happen. Failures are the exception: they always get through.

TELEMETRY

Know what the work cost

Timeline, spend, quota, and session history live one hover away. Tokens and cost per agent, quota windows watched before they wall you, and a full record of what finished while you were away.

SHELF

Stash anything in the notch

Drag files, images, links, or text onto the notch and they wait on the shelf. Drag a card back into Finder, a browser upload field, or an editor. A size budget evicts the oldest items on its own.

WORKSPACE

Tile the whole workspace

An infinite horizontal window strip with spring physics, width presets, an overview mode, and auto-chaining that lines up your IDE, browser, and terminal. Plus a desktop HUD for the map of it all, on one hotkey.

How it works

From a dozen panes to one watch post

01

Agents report in

Herdr, tmux, and Zellij panes stream status directly. Standalone terminals and OpenCode report through a small local plugin. No cloud, no account.

02

The notch triages

Blocked agents pin to the top with the exact request. Working agents tick quietly. Finished agents settle before they are allowed to interrupt you.

03

You answer once

Click a choice, press a number key, or type a reply. Bantay confirms the write reached the agent before the card leaves, and records a receipt for every decision.

Get Bantay

On your notch in two commands

Bantay-TUI runs on macOS 13 or later, on Apple Silicon and Intel. Build it from source:

git clone https://github.com/8-BitRhyon/bantay-tui.git
cd bantay-tui
swift build -c release
bash scripts/setup.sh

The setup script installs a signed app bundle and a launch agent, so Bantay starts at login. Prebuilt downloads land on the releases page. Herdr, tmux, Zellij, and OpenCode integrations can be enabled from Settings after first launch.
