Bantay-TUI is a native macOS control plane for AI coding agents. It lives in the MacBook notch: see who is working, answer their questions, approve their actions, and never lose track of a background agent again.

Built for parallel agents

You run Claude Code, OpenCode, Codex, and Gemini across Herdr, tmux, Zellij, and IDEs. Bantay gives all of them one surface, and it stays quiet until you are needed.

APPROVALS

Answer from the notch

Permission requests show the exact command, path, or question with a risk badge. Allow once, deny, or answer numbered choices and multi-selects inline. Nothing approves blind.

QUESTIONS

Forms, mirrored faithfully

When an agent asks a question, the card copies its form: one tappable row per option, with each option's description underneath. Type a custom answer when none of the options fit.

QUIET BY DEFAULT

Done means done

Agents report "done" at every turn boundary. Bantay waits until a finish settles, and while you are working in another pane it holds completions silently. Failures always interrupt. Finishes while you watched the pane never pop at all.

TELEMETRY

Spend, quota, sessions

Timeline, spend, quota, and session history live one hover away. Track tokens and cost per agent, watch quota windows before they wall you, and replay what finished while you were away.

SHELF

A shelf in the notch

Drag files, images, links, or text onto the notch to stash them. Drag a card back into Finder, a browser upload field, or an editor. Old items evict themselves.

WINDOW STRIP

Infinite strip tiling

A horizontal window manager with spring physics, column presets, an overview mode, and auto-chaining that lines up your IDE, browser, and terminal. Toggle it from the CLI or a hotkey.

How it works

01

Agents report in

Herdr, tmux, and Zellij panes stream status directly. Standalone terminals and OpenCode report through a small local plugin. No cloud, no account.

02

The notch triages

Blocked agents pin to the top with the exact request. Working agents tick quietly. Finished agents settle before they are allowed to interrupt you.

03

You answer once

Click a choice, press a number key, or type a reply. Bantay confirms the write reached the agent before the card leaves, and records a receipt for every decision.

Install

Bantay-TUI runs on macOS 13 or later, on Apple Silicon and Intel. Build it from source:

git clone https://github.com/8-BitRhyon/bantay-tui.git
cd bantay-tui
swift build -c release
bash scripts/setup.sh

The setup script installs a signed app bundle and a launch agent, so Bantay starts at login. Prebuilt downloads land on the releases page. Herdr, tmux, Zellij, and OpenCode integrations can be enabled from Settings after first launch.
